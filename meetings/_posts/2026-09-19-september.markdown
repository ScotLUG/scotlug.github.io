---
title: Repair Cafe / Linux Install Day
---

To celebrate [Software Freedom Day](https://digitalfreedoms.org/en/sfd) ScotLUG will running a repair cafe and linux install afternoon at [The Gamer Club](https://www.thegamerclub.co.uk/gettinghere) in Glasgow.

The event will run from 12:00 to 16:30 at the Gamer Club!

The Gamer Club can be found in Central Glasgow at [153 Bath Lane, Glasgow, G2 4RH](https://www.thegamerclub.co.uk/gettinghere) and directions can be found on The Gamer Club website at: [https://www.thegamerclub.co.uk/gettinghere](https://www.thegamerclub.co.uk/gettinghere)

This will be an opportunity to find out about Open Source Operating Systems and have an opportunity to try a LiveUSB of Linux or OpenBSD to find out more about Linux.

There will also be an opportunity have the ScotLUG look at repairing old hardware / laptops and see if we can revive them!

If you would like to help please contact us.
